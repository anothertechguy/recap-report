# The Recap Report

An American news publication covering culture, business, lifestyle, health, sports, and entertainment — rooted in Atlanta, GA.

## Tech Stack

- **Vite** + **React 18** + **TypeScript**
- **Tailwind CSS** + **Framer Motion**
- **shadcn/ui** components

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
